# ScamShield

ScamShield is a hackathon-ready cybersecurity web app for analyzing suspicious SMS messages, emails, direct messages and URLs.

## Features
- Premium dark red cybersecurity dashboard
- Text, email, URL and screenshot workflows
- Explainable 0–100 risk score
- Detection for urgency, OTP/password requests, risky links, prize scams, money requests, impersonation and personal-data requests
- Detailed safety recommendations
- Local scan history with search/filter
- URL checker and email-header analyzer
- Safety tips and reports dashboard
- Demo login/sign-up modal
- Dark/light appearance toggle
- Fully responsive mobile design
- No framework or build step required

## Run locally
Open `index.html` directly in a browser or use VS Code Live Server.

## Deploy to GitHub Pages
1. Create a repository named `ScamShield`.
2. Upload all files from this folder.
3. Commit to `main`.
4. Go to **Settings > Pages**.
5. Choose **Deploy from a branch** and select `main` / root.
