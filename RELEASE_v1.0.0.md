# ScamShield v1.0.0 — Release Notes

First public hackathon release.

### Highlights
- Explainable scam/phishing risk scoring
- Message, email and URL workflows
- History, reports and safety guidance
- Responsive cyber-themed interface
- GitHub Actions for validation and Pages deployment

### Known limitations
- Detection is heuristic, not a trained ML model.
- Screenshot/image analysis does not yet perform OCR.
- Authentication is demo/local only.
