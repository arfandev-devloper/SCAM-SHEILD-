# GitHub Project Management Setup

Some GitHub features are configured on GitHub rather than stored as source files.

## Recommended labels
- `bug`
- `enhancement`
- `documentation`
- `security`
- `ui-ux`
- `good first issue`
- `help wanted`

## Milestones
- v1.1 — Detection improvements
- v1.2 — OCR & URL intelligence
- v2.0 — Secure AI backend

## Project board
Create columns: **Ideas → To Do → In Progress → Testing → Done**.

## Discussions
Enable Discussions in repository Settings for Q&A, ideas and hackathon feedback.

## Pull requests
Use feature branches and the included pull-request template.

## Releases
Create a Git tag such as `v1.0.0`, then publish a GitHub Release with highlights from `CHANGELOG.md`.
