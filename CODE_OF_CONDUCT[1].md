# Code of Conduct

## Our pledge
We want ScamShield to be a welcoming, respectful and collaborative project.

## Expected behavior
Be respectful, give constructive feedback, respect privacy, credit others' work, and focus discussions on improving the project.

## Unacceptable behavior
Harassment, discrimination, threats, doxxing, spam, malicious code, or publishing another person's private information is not acceptable.

## Enforcement
Project maintainers may edit or remove contributions or discussions that violate these standards and may restrict participation when necessary.

For conduct concerns, contact the repository maintainer through a private GitHub channel rather than posting sensitive information publicly.
