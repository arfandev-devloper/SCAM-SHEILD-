# Security Policy

## Reporting a vulnerability
Please do **not** publish exploitable security vulnerabilities in a public issue. Contact the repository maintainer privately through GitHub and include the affected file/function, impact, and safe reproduction details.

## Secrets
Never commit API keys, passwords, access tokens or private credentials. Use `.env` locally and keep `.env.example` limited to placeholder names.

## Scope
ScamShield v1 is an educational/hackathon project. Its heuristic result should be treated as a warning aid, not a guarantee that a message or URL is safe.
