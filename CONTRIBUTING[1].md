# Contributing to ScamShield

Thanks for helping improve ScamShield.

## Workflow
1. Fork the repository.
2. Create a feature branch: `git checkout -b feature/short-name`
3. Make one focused change.
4. Test the interface and run `npm run check`.
5. Commit with a clear message.
6. Push your branch and open a pull request.

## Contribution ideas
- Improve scam-signal rules and explanations.
- Add accessibility improvements.
- Add tests.
- Improve responsive UI.
- Add safe backend integrations for AI/OCR/URL reputation.

## Rules
- Never commit API keys, passwords, tokens or personal data.
- Do not add real phishing payloads that could endanger users.
- Clearly label demo metrics and simulated features.
- Keep changes understandable and documented.
